# MyOS
My own operating system written in C/C++ as a learning project.
# About
This project is an attempt to develop my own operating system from scratch while learning how operating systems work internally.
The main goal is to understand the fundamentals of OS development, low-level programming, memory management, hardware interaction, and system architecture.
The project is based on the tutorial:
•	OS in 1,000 Lines
# Goals
•	Learn how operating systems work.
•	Improve my C/C++ programming skills.
•	Understand low-level programming.
•	Explore memory management and hardware interaction.
•	Build a simple operating system step by step.
# Development Environment
•	OS: Lubuntu (Linux)
•	Languages: C / C++
•	Architecture: RISC-V
•	Tutorial: OS in 1,000 Lines
